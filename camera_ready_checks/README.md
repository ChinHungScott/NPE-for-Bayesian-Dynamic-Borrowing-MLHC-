# Camera-ready supplementary checks

This folder contains small supplementary analyses added during the MLHC
camera-ready revision.

- `run_npe_ols_perturbation.py`: perturbation check for the OLS-derived
  coefficient-difference summary block used by the main NPE model.
- `npe_ols_perturbation_summary.csv`: summary table reported in the appendix.
- `run_covariate_effect_check.py`: limited illustrative check for a
  target-aware covariate-effect parameter.
- `covariate_effect_summary.csv`: summary table reported in the appendix.

These checks are intended to support the appendix discussion. They are not the
main simulation pipeline.
